90. keyd 交换 Caps Lock 和 Ctrl 配置流程

# 1. 安装依赖
sudo apt install git meson gcc libudev-dev

# 2. 从源码安装 keyd
git clone https://github.com/rvaiya/keyd /tmp/keyd
cd /tmp/keyd
make
sudo make install

# 3. 写入配置
sudo tee /etc/keyd/default.conf << 'EOF'
[ids]
*

[main]
capslock = leftcontrol
leftcontrol = capslock

[control]
h = left
j = down
k = up
l = right
EOF

# 4. 创建 systemd service
sudo tee /etc/systemd/system/keyd.service << 'EOF'
[Unit]
Description=Keyd remapping daemon
After=local-fs.target
Before=display-manager.service

[Service]
Type=simple
ExecStart=/usr/local/bin/keyd
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

# 5. 启动并设为开机自启
sudo systemctl daemon-reload
sudo systemctl enable --now keyd

# 6. 验证
sudo keyd monitor

关键点：
- Ubuntu apt 里的 keyd 是 PGP keyserver，不是键盘重映射工具，必须从源码编译 rvaiya/keyd
- keyd 工作在内核输入层，Wayland 和 ibus 均无法绕过
- 配置中用 leftcontrol 而非 ctrl
